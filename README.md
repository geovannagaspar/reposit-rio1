# reposit-rio1
Projeto Pokémon
Sobre o projeto

Esse projeto foi feito para aprender a consumir uma API usando JavaScript.

Nele é possível pesquisar um Pokémon pelo ID e visualizar suas informações em uma cartinha.

O que o projeto faz?
Busca Pokémon pelo ID.
Mostra o nome e a imagem.
Mostra a experiência base.
Mostra a altura e o peso.
Exibe tudo em formato de uma carta Pokémon.
Tecnologias utilizadas
HTML
CSS
JavaScript
PokéAPI
API utilizada

https://pokeapi.co/

Como usar
Abra o projeto no VS Code.
Execute o arquivo index.html com o Live Server.
Digite o ID de um Pokémon.
Clique em Buscar.
As informações vão aparecer na cartinha.
Arquivos
index.html: estrutura da página.
styles.css: aparência e estilo da cartinha.
main.js: busca os dados na API e mostra na tela.
Conclusão

Com esse projeto pratiquei como consumir uma API usando fetch e async/await, além de trabalhar com HTML, CSS e JavaScript.
